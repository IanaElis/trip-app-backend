# trip-app-backend
TripApp is a travel management application that allows users to create trips, organize itineraries, manage reservations and activities, visualize destinations and points of interest on an interactive map, and receive notifications about upcoming events.

It allows easy access to the documents like booking, confirmation and ticket details. 
This helps travellers manage an increasing amount of travel-related information instead of relying on fragmented digital storage, such as emails, screenshots or local files and notes.

- Backend: https://github.com/IanaElis/trip-app
- Frontend: https://github.com/IanaElis/trip-app-frontend
